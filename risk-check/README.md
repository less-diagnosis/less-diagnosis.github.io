# 妻に話す前に確認する、レス悪化危険度チェック

note記事からリンクするための静的診断ページです。HTML / CSS / JavaScriptだけで動き、外部APIは使いません。

## ローカルでの開き方

`index.html` をブラウザで開くと、そのまま診断ページを確認できます。

GitHub Pagesで公開する場合は、このフォルダ内の `index.html`、`style.css`、`script.js`、`README.md` をリポジトリに置いて公開してください。

## 質問文や結果文の編集方法

質問文は `script.js` の `QUESTIONS` 配列を編集します。

回答の選択肢と点数は `script.js` の `OPTIONS` 配列を編集します。現在は以下の3択です。

- 0点：ほとんど当てはまらない
- 1点：少し当てはまる
- 2点：かなり当てはまる

結果の判定名、説明文、推奨アクションは `script.js` の `RESULTS` 配列を編集します。点数範囲を変える場合は、各結果の `min` と `max` を変更してください。

noteへのリンク先は `index.html` 内の `TODO_NOTE_URL` を、公開後のnote記事URLに置き換えてください。

## 文面編集時の注意

このページは医療・心理・法律の専門診断ではなく、夫側の行動や家庭内の空気を見直すためのセルフチェックです。妻の気持ちを断定する表現や、相手を操作するような表現は入れないでください。
